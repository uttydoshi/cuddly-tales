Cuddly Tales architecture

A parent picks characters, an LLM writes a story starring their child, a safety and age check reads it, and it streams to the phone word by word, then is saved to read again, page by page. An agent can also plan a whole adventure, one chapter a day, with every step shown. The Angular app and the FastAPI API run on AWS, defined with the CDK, alongside ukdoshi.com and lab.ukdoshi.com; every model call is traced in Langfuse. Dashed parts come next.
