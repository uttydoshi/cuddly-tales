Cuddly Tales architecture

A parent picks characters, an LLM writes a bedtime story starring their child, and the story streams to the phone word by word, then is saved to read again. The Angular app and the FastAPI API run on AWS, defined with the CDK, alongside ukdoshi.com and lab.ukdoshi.com. Dashed parts come next.
