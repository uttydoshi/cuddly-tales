Cuddly Tales cocoon

The first slice runs end to end: pick characters, generate a bedtime story through LiteLLM, stream it word by word, save it, then read it from the story list. Everything dashed comes later and only plugs into the boxes already here.

What runs where

One story, start to finish

Scope of this slice

In the cocoon

  • Child profile (Mira, 3) and the seed cast, loaded on first start
  • Pick characters, generate, watch the story stream
  • Story saved with text, word count and reading time
  • Story list and story view
  • pytest for every endpoint, with the LLM call faked

Comes after

  • Edit and delete for characters and stories
  • Plot cards and drag-and-drop storyboard
  • Safety and age check, Langfuse tracing
  • Adventure agent, scheduled chapter, dashboard
  • Postgres and the Render deploy
